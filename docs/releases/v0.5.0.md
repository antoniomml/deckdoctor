# DeckDoctor 0.5.0

DeckDoctor 0.5.0 adds an interactive dashboard and turns the diagnostic tool into a day-to-day companion for handheld gaming PCs.

- Running `deckdoctor` in a terminal now opens a dashboard with six tabs: Overview, Checks, Monitor, Games, Fixes and Report. Scripts, pipes, `--json`, `--output`, `--compare`, `-v`, `--ascii`, `TERM=dumb` and `DECKDOCTOR_NO_TUI=1` keep the classic text output. `deckdoctor diagnose` forces it.
- The device is identified by model (Steam Deck LCD/OLED, ROG Ally family, Legion Go family, MSI Claw, GPD, AYANEO, OneXPlayer, AYN, Zotac Zone) and APU.
- The live monitor shows CPU/GPU load and clocks, APU power against the TDP limit, APU/SSD/battery temperatures, fan speed, battery draw and time left, the negotiated USB-PD charger wattage, memory, swap and the busiest processes. Graphs use fixed scales so readings stay comparable.
- The Games tab lists every installed game with size, Proton prefix, shader cache, Proton version, playtime and last played, flags pending updates with their download size, and lists leftovers (prefixes and shader caches of uninstalled games or removed non-Steam shortcuts) with their Steam Cloud status. Leftovers are never deleted.
- Fixing is integrated: fixable problems are marked wherever they appear, with a *Fix it* button in each check, *Fix all* in the overview and the Fixes tab, and the `f` key. A single confirmation dialog lists exactly what changes and how to undo it. The terminal is handed over while fixes run, then a fresh scan verifies the result and a notification says whether the problem is gone.
- New checks: HW-THERMAL (temperatures and fan) and STEAM-STORAGE (leftover space). HW-BATTERY now reports health against design capacity, draw and time left.
- Markdown reports show storage as readable free/total sizes.
- Textual is now a runtime dependency and is bundled in the release binary. If it is missing, the CLI explains why and prints the text diagnosis.

Validated on a Steam Deck LCD running SteamOS 3.8.16: 45 games across internal storage and microSD, 1.7 GB of leftovers detected, storage scan in under 0.1 s and full size measurement in about 0.3 s.

The release passed 175 tests, Ruff, and mypy. The fix flow was also exercised end to end with the release binary in a real terminal.
