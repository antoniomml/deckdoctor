# DeckDoctor 0.4.1

DeckDoctor 0.4.1 improves terminal feedback while diagnostics and fixes are running.

- Diagnostics now use a single updating progress line with the current check and completion percentage.
- Fixes announce prerequisite checks and long-running commands before execution.
- Completed fixes are labeled as results instead of appearing to start after they have finished.
- Compact comparisons show status changes and leave measurement-only changes to `--verbose`.
- Fix plans are described as available rather than safe when their declared risk is medium.

The release passed 138 tests, Ruff, and mypy.
