# DeckDoctor 0.4.0

DeckDoctor 0.4.0 turns the general scan into a symptom-oriented handheld diagnostic while making every “healthy” result more explicit about what was actually verified.

## Highlights

- Ten focused workflows: Decky, updates, libraries, games, controllers, battery, resume, audio, docks and performance.
- Steam library diagnosis preserves disconnected library paths and checks access, free space and mount metadata.
- `--appid` inspects a game's manifest, install directory, explicit compatibility override, installed runtimes, Proton prefix and bounded log metadata.
- Battery, input, suspend/resume, display, audio and system-pressure observations include clear limits and guided manual checks.
- `--compare` compares JSON reports created with the same scope, language, AppID and network posture.
- Compact output adapts to narrow terminals and always exposes skipped and unknown checks.

## Trust and repair behavior

- Invalid or partly invalid `--only` filters now fail with a usage error.
- A restricted D-Bus connection is UNKNOWN instead of an updater failure.
- Steam Beta alone no longer creates an incompatibility diagnosis.
- Fix plans are revalidated before mutation and checked again afterward.
- Flatpak and Decky fixes report the exact attempted command; partial command success is no longer treated as a completed repair.
- JSON reports distinguish command completion (`ok`) from observed resolution (`verified`).

## Validation

The release passed 134 tests, Ruff, mypy and a PyInstaller build. Its read-only checks were exercised on a Steam Deck running SteamOS 3.8.16 with internal and microSD Steam libraries. No controller-native Gaming Mode interface is included yet, and Bazzite/CachyOS still need physical validation.
